SADAR Finance is a financial web application designed around a practical problem: everyday spending is easy to overlook until it accumulates. The product combines day-to-day transaction tools with analysis and guidance so financial information is easier to understand and act on.

As Full Stack Web Developer, I worked on the application connections that turn separate product capabilities into a usable system. That included backend and API services, protected access, relational data integration, and the bridge between the React interface and Node.js services.
